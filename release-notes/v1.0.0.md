## FAMS v1.0.0 — 首个正式版

集团固定资产台账管理系统。组织主数据（公司 / 部门 / 员工）与资产卡由星瀚 ERP 托管、每日凌晨定时同步；台账侧负责卡片维护、财务信息批量更新、二维码标签与盘点执行，并含设备维修流程。

### 功能范围

| 模块 | 内容 |
|---|---|
| 主数据同步 | 公司 / 部门 / 员工 + 资产卡，每日 00:00 先组织、后资产卡；支持手动触发与 dry-run 预检 |
| 资产台账 | 卡片维护、财务信息批量更新（Excel 导入）、二维码标签打印、盘点计划与执行 |
| 维修流程 | 报修 → 受理 → 派工 → 维修 → 确认完工 → 完成（含驳回 / 撤销分支） |
| 首页看板 | 按角色显示「待我处理」与资产 / 流程概况 |
| 分类可维修标签 | 仅设备类资产可提交维修单，三层拦截（数据层标记 + 后端 400 + 前端隐藏按钮） |

### 部署

```bash
# 1. 替换二进制（服务器上的 config.yaml / .env / cert/ 保持不动）
scp asset-mgr-linux-amd64 root@<host>:/tmp/asset-mgr.new
ssh root@<host> 'set -e
  cp -a /opt/asset-mgr/asset-mgr /opt/asset-mgr/asset-mgr.bak-$(date +%Y%m%d-%H%M%S)
  chmod 755 /tmp/asset-mgr.new && chown root:root /tmp/asset-mgr.new
  mv -f /tmp/asset-mgr.new /opt/asset-mgr/asset-mgr
  systemctl restart asset-mgr && sleep 4 && systemctl is-active asset-mgr'

# 2. 确认服务在听
curl -s -o /dev/null -w "%{http_code}\n" http://<host>:8080/
```

也可用仓库内 `deploy/upload_binary.py`（从环境变量读 `SSH_HOST` / `SSH_USER` / `SSH_PW`，不落盘凭据）。

### 上线前必改

1. `config.yaml` 的 `auth.jwt_secret` 换成随机值
2. `auth.init_admin_password` 换掉，或首次登录后改密
3. 数据库账号换成只对 `asset` 库有权限的专用账号（见 README「上线前必须改」）

### 已知事项

- 分类「其他」（0299）下约 51 张资产默认不可维修，报修入口已隐藏。如需报修，由管理员在「分类管理」页把该分类改为可维修，或把资产重新归类。
- Go 测试套件默认连生产库（项目内无独立测试库），`go test ./...` 会读写生产库，跑完需确认零残留。
- 维修工（repair_tech）可见全部资产，为既有行为（需查资产才能维修）。
