### 令牌层：用「字节偏移 + 活体计算值」双证

CSS 自定义属性的层叠规则是**同特异性时源序靠后者胜出**，所以偏移量本身就是证据。
但 ⚠️ **必须用带前缀的完整声明去搜** —— 搜裸十六进制会先命中令牌文件顶部的 `--ink:#14171b`，
得到一个**早于**覆盖点的偏移，看起来像「覆盖没生效」：

| 声明 | 库默认偏移 | 本仓覆盖偏移 | 结论 |
|---|---|---|---|
| `--el-color-primary` | 1997（`#409eff`） | **363941**（`#14171b`） | 后者胜出 ✓ |
| `--el-border-radius-base` | 692（`4px`） | **365357**（`2px`） | 后者胜出 ✓ |
| `--el-table-header-bg-color` | 272519（`.el-table` 上） | **366403**（`.el-table` 上） | 后者胜出 ✓ |

活体取证（`C:/tmp/prod-token-probe.js`，直接对**生产页面**注入探针元素读计算值）：

```
primary #14171b   radius 2px   ink #14171b   signal #f5b301
steel100 #eef1f4  steel500 #656d79  warn #bd7014
bodyBg rgb(246,247,249)
.el-table → headerBg #eef1f4  headerFg #5c6470  hoverBg #eef1f4
            border #dde1e6    textColor #3d454f
普通 div → --el-table-header-bg-color: ""      ← 对照组
运行时异常 0 条
```

**对照组 `""` 是决定性的**：普通 `div` 取不到该变量 ⇒ 证明 Element Plus 把它声明在 `.el-table` 上
而**不是** `:root` ⇒ 反证「当初写在 `:root` 的覆盖必然失效」。这正是本轮修掉的一个真 bug（见下）。

## 本轮验收阶段暴露并修掉的三个真 bug

1. **表头底色不生效** —— `--el-table-*` 原本写在 `:root`，被 EP 在 `.el-table` 上的声明压掉
   （元素自身声明的自定义属性永远赢过继承值）。改到 `.el-table { … }` 后生效。
2. **侧栏高亮整条丢失** —— 菜单 index 可能是 `/repairs` 也可能是 `/repairs?mine=1`
   （取决于权限算出的维修入口），而 `route.path` 只有 `/repairs`，直接拼 query 去比一个都不匹配。
   改为两级匹配（完整 index 精确命中 → 退化到只比路径）。
3. **三处对比度不达标** —— `--steel-500 #6b7480` 白底 4.74 达标但**纸底仅 4.42**、表头底 4.18；
   `--warn #c9781a` 表头底 2.99（低于图形 3:1）；`.crumb-sep` 用 `--steel-300` 白底仅 1.67。
   ⇒ 改 `#656d79` / `#bd7014` / 改引 `--steel-500`，一处令牌修复 15 个调用点，复测 14 路由全 ≥4.5:1。
