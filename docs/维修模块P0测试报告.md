## 5. 非阻塞观察（非本次引入，供参考，不影响判定）

1. **路由无权限守卫**：`web/src/router/index.ts` 的 `beforeEach` 只校验登录态，不校验角色权限。理论上受限账号可**直接改 URL** 进入 `/sync`、`/repairs` 等页面（菜单已隐藏），页面加载后调写接口会得到 403。此为**既有设计**（菜单隐藏 + 后端 403），非本次提交引入，本次未扩大该面。
2. **`CardForm` 编辑 `status` 对「维修中」卡的表现**：卡若 `biz_status='维修中'`，其 `form.status` 仍是「在用」；管理员在卡片编辑里改 `status` 不会改变列表/详情显示的「维修中」（biz_status 优先，且 biz_status 只由单据写）。符合「状态真相由单据驱动」的设计约定，但可能让管理员困惑，建议后续在 UI 上加一句说明。
