## 改了什么

### 金额列

- `web/src/api/meta.ts`：「金额」列 `defaultOn: true → false`（原值 / 净值本来就关着）
- `web/src/views/asset/List.vue`：页头去掉「金额合计」，只剩「共 N 条」；窄屏卡片同步删掉「金额」行；移除 `amountTotal` ref 与其赋值

⚠️ **本次最容易被「假通过」骗过的地方**：列配置存在 `localStorage`，而**已存值优先于列定义的默认值**。
只改 `defaultOn`，老用户刷新后**照样看得见金额列**。故加了一次性迁移：

```
key: asset_list_columns → asset_list_columns_v2
读旧 key → 剔掉 money 类列（amount / fin_original_value / fin_net_value）→ 写新 key → 删旧 key
```

迁移后新 key 是权威，用户**再手动打开金额列能正常保留**（这条专门验过）。

### 扫码找资产

- 从工具栏「更多」下拉提到**页头右侧**，与「新建资产」同一行，**不限权限**（所有角色可见）
- 信号黄 `#f5b301` 白底对比度仅 **1.85:1**，达不到图形 3:1 ⇒ **只做左侧 3px 描边**（`box-shadow: inset 3px 0 0 var(--signal)`），文字用墨色，实测 **9.71:1**
- 「更多」只剩「导出 Excel」「列配置」；两者本就只对桌面有意义 ⇒ **窄屏不再渲染「更多」**，否则会剩一个点开什么都没有的空下拉

## 本轮踩到的新坑（环境层）

### ⚠️ Git Bash 的 MSYS 路径转换会改写**环境变量**

`yzj_sftp.py` 靠环境变量 `REMOTE` 传远端路径，本轮首次出现：

```
export REMOTE=/opt/asset-mgr/asset-mgr.new
→ Python 实际读到 C:/Users/admin/.workbuddy-ai/binaries/PortableGit/versions/1.2.0/opt/asset-mgr/asset-mgr.new
→ SFTP open() 报 FileNotFoundError: [Errno 2] No such file
```

不是权限、不是远端目录问题（同目录写探针文件成功），是**入参被 MSYS 当成 POSIX 路径转换**。
**修复**：调用前加 `MSYS_NO_PATHCONV=1`。已实测 `MSYS2_ARG_CONV_EXCL='*'` **无效**，只有 `MSYS_NO_PATHCONV=1` 有效。

排查路径记录：先确认 SFTP 会话本身正常（`normalize('.')` / `listdir` / `stat` 全部 OK）→ 再单独测向目标路径写入（成功）→ 说明是**入参**而不是**权限** → 打印 Python 实际读到的环境变量值 → 一眼看出被改写。
